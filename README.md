# DotAgency — Digital Agency Website

Live: **https://dot-agency.vercel.app** · Repo: **ENG-AHMEDHUS/DotAgency**

Modern digital agency website built with React + Vite + Tailwind CSS.

## ✨ Features
- Responsive agency landing (hero, services, portfolio, contact)
- Reusable React components
- Fast Vite build + Vercel deployment

## 🛠️ Tech Stack
React, Vite, Tailwind CSS, JavaScript, ESLint, PostCSS, Vercel

## 🚀 Run locally
```bash
git clone https://github.com/ENG-AHMEDHUS/DotAgency.git
cd DotAgency
npm install
npm run dev
```

## 📦 Build
```bash
npm run build
```

## 📁 Structure
```
src/          # components, pages, assets
public/       # static files
vite.config.js
tailwind.config.js
vercel.json
```
